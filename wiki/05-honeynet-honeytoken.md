# 蜜網與蜜標

**一句話：蜜網是「一整個假的網路」，蜜標是「一筆假的資料」；三者是同一個想法的不同尺寸。**

## 蜜網（Honeynet）
- 由多個蜜罐組成、模仿真實網路的環境，有伺服器、資料庫、路由器。[S2][S3]
- 好處：可以看到攻擊者如何在系統之間移動，並讓他停留更久。[S2][S3]
- The Honeynet Project 就是以此為名的國際研究組織，1999 年成立。[S8][S4]

## 蜜標（Honeytoken）
- 放在「真實系統裡」的假資料：假帳號密碼、假 API 金鑰、誘餌文件、資料庫裡的假資料列。[S6]
- 沒有任何正當用途，所以只要有人碰到就發警報。[S6]
- NIST 定義本來就包含「一個檔案」也可以是蜜罐，蜜標正是這個想法。[S1]

## 三者比較
| | 蜜標 | 蜜罐 | 蜜網 |
|---|---|---|---|
| 尺寸 | 一筆資料 [S6] | 一個系統 [S1] | 一整個網路 [S3] |
| 成本 | 很低 [S6] | 中 | 高 |
| 回答的問題 | 「有沒有人碰了不該碰的東西？」[S6] | 「攻擊者進來後做了什麼？」[S6] | 「攻擊者怎麼在系統間移動？」[S2] |

## 蜜標的使用循環
部署（放在攻擊者會找、正常人不會碰的地方）→ 偵測（接上警報系統）→ 回應（當成入侵處理）[S6]

## 給新手的比喻
> 蜜標 = 在抽屜放一張「保險箱密碼」紙條，其實是假的，有人拿去用就會響鈴；蜜罐 = 假保險箱；蜜網 = 一整間假銀行。
