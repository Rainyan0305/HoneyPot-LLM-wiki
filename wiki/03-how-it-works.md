# 蜜罐怎麼運作？

**一句話：放誘餌 → 等人上鉤 → 全程記錄 → 分析 → 拿去強化真正的防禦。**

## 五個步驟
1. **擺誘餌**：架一個看起來像真實伺服器、資料庫或網路設備的假系統，裡面沒有真正有價值的東西。[S3][S7]
2. **留破綻**：故意留下「不會太明顯」的弱點，例如弱密碼、開著常見連接埠，讓它更像真的。[S3][S7]
3. **全程記錄**：攻擊者的每個動作都被默默記下來。[S3]
4. **分析**：從紀錄看出攻擊者從哪裡來、用什麼工具、想做什麼。[S3]
5. **回饋**：把發現拿去修補漏洞、更新偵測規則與防火牆規則。[S2]

## 能蒐集到哪些資料？
- 攻擊者的 IP 位址 [S7]
- 他試過的帳號密碼、取得的權限 [S7]
- 他存取、修改、刪除了哪些資料 [S7]
- 他想上傳的惡意程式和工具 [S7]
- 例：開源的 SSH 蜜罐 Cowrie 會記錄暴力破解登入、登入後輸入的每個指令，還會把攻擊者下載的檔案存起來，連線過程可以重播。[S5]

## 為什麼資料特別「乾淨」？
- 正常使用者不會去用蜜罐，所以進來的流量幾乎都是惡意的，分析師不用花時間分辨好人壞人。[S2][S3]

## 給新手的比喻
> 像在超市放一個「沒標價的試吃攤」，旁邊裝攝影機。會偷偷把整盤帶走的人，一舉一動都被錄下來，店家就知道下次要怎麼防。
