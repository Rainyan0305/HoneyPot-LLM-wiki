# 摘要（以自己的話改寫）
- NIST 把蜜罐定義為：一個系統（例如網頁伺服器）或系統資源（例如伺服器上的一個檔案），刻意設計成對入侵者有吸引力，就像蜂蜜吸引熊。
- 重點：蜜罐不一定是整台機器，也可以只是一個「資源」（一個檔案）→ 這是後來「蜜標 honeytoken」概念的根源。
- 定義來源：CNSSI 4009-2015，最初出自 IETF RFC 4949。

# 可抽出的主張（claims）
- C1.1 蜜罐 = 刻意吸引入侵者的系統或系統資源。
- C1.2 蜜罐的範圍可小到一個檔案。
